**指标定义**
- **Accuracy**：每台可评估设备只归入一类。故障并且及时命中、或者正常并且没有报警，算正确；Accuracy = 正确设备数 ÷ 可评估设备数。随访未知的设备不计入。因为正常设备占 99% 以上，Accuracy 总是很高，所以要和 F1、平衡准确率（召回率与特异度的平均）一起看；
- **模型参数量**：部署模型（截断到部署轮数）中所有分裂节点的阈值数 + 所有叶子节点的输出值数；
- **自动化覆盖率**：人工干预**只统计修改预算**（`agent.py limits`，记录为 `limits_changed` 事件）。步骤级 = 自动步骤数 ÷（自动 + 人工步骤数），自动步骤包括假设生成、分析决策、训练、交叉验证、诊断、特征预筛和采纳判断；实验组级 = 从上一组完成到本组完成之间没有人工干预的实验组比例；全流程 = 搜索从开始到结束没有任何人工干预。会话建立、数据准备、TEST 评估这些在闭环之外由人启动的命令不计入；
- 历史 TEST 时间段在项目早期被查看过，这些测试成绩是回顾性评估，不是新的独立盲测。

## 复核名单：低于阈值、但排名靠前的设备

报警阈值不变。没有报警的设备按本期最高分排序，取前 K 台组成**复核名单**，交给人来判断（`tools/review_list.py`）。K 应该由"运维人员每期能复核多少台设备"来决定，不能按标签或测试结果来挑，所以下面同时列出四档，不挑选其中某一档。名单里的故障设备，只有当它在预警窗口内的分数也达到名单门槛时，才算"及时被复核发现"。

| 评估 | 复核 0.25% | 复核 0.5% | 复核 1% | 复核 2% |
|---|---|---|---|---|
| TypeA 确认窗口（40 台故障；只看报警时召回 30.0%） | +4 台 → 40.0% | +5 台 → 42.5% | +5 台 → 42.5% | +7 台 → 47.5% |
| TypeA 历史 TEST（101 台故障；只看报警时召回 26.7%） | +10 台 → 36.6% | +12 台 → 38.6% | +21 台 → 47.5% | +31 台 → 57.4% |
| TypeB 确认窗口（7 台故障；只看报警时召回 42.9%） | +2 台 → 71.4% | +2 台 → 71.4% | +2 台 → 71.4% | +2 台 → 71.4% |
| TypeB 历史 TEST（12 台故障；只看报警时召回 0%） | +2 台 → 16.7% | +2 台 → 16.7% | +3 台 → 25.0% | +3 台 → 25.0% |
| 硬盘历史 TEST（804 台故障；只看报警时召回 43.3%） | +76 台 → 52.7% | +122 台 → 58.5% | +193 台 → 67.3% | +271 台 → 77.0% |

（表中的百分比是名单大小占可评估设备的比例；"+N 台 → X%"表示名单里及时发现的故障数，以及"报警 + 复核"的总召回率。）

- 名单越小，名单里故障设备的比例越高（各档在 1.1%～11.8% 之间），在所有档位上都比随机抽查高出约 9 倍以上；
- 这是**运行时的人工复核**，和统计调优过程自动化覆盖率时的"人工干预"（修改预算）是两回事；
- 复核名单这个想法是在看过 TypeB 测试结果之后提出的，上表只说明它在这些时间段上的效果，不是独立验证。

## 目录结构

每个结果目录的结构相同：`session/`（完整搜索记录）、`confirmation/`（确认窗口评估）、`historical_test/`（TEST 评估）、`summary.md` / `summary.json`（比赛指标）、`run_scripts/`（实际执行的脚本）、`logs/`（运行日志）。

新结果放进来的步骤：
1. 把服务器上的会话目录复制到 `results/<名称>/session/`，排除 `cache/`、`*.npy`、`*.parquet` 和 CV 各折模型这些大文件；
2. 把 `confirm_search.py` 的输出复制到 `results/<名称>/confirmation/`，TEST 评估结果复制到 `historical_test/`；
3. 运行 `python tools/session_report.py --session results/<名称>/session --json results/<名称>/summary.json --md results/<名称>/summary.md`；
4. 在本表和根目录 README 的"结果一览"里补上一行。

v3.1 及更早的实验快照可以在 git 提交 `4c27cf1` 中查看。
