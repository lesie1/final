## 审查问题复现与修复

原版 57 项测试全部通过，但缺少对实际失败入口的覆盖。新增最小复现确认了新输入缺缓存、冻结采样拒绝设备权重、路径关键字触发资源误判三种问题。

新增回归进一步覆盖：

- `init → run` 从数值原始输入构建缓存、真实训练、默认 CV；无测试侧手工 normalize。
- memory/hdd 新会话 prepare；缺失共享缓存不重建；init 后输入变更被拒绝。
- 继承旧缓存和冻结采样后，sample/device 的特征、标签和设备顺序相同；权重变化符合定义。
- 设备权重的实际 CV 训练，采样篡改和标签期限改变仍被拒绝。
- 目录或普通异常文本包含 memory/cuda/disk，不被视为资源证据。
- 真实子进程中的 MemoryError、磁盘满、明确 CUDA 内存分配失败和普通错误分类。
- 资源错误无法写入异常记录时，专用退出码仍可使控制器正确暂停。

首轮修复回归发现一个旧用例只比较权重说明文字，已改为检查实际每设备权重质量；最终 67 项均通过。

## 复现边界

公开仓库不附带真实数据和采样文件，其他环境可以运行合成回归测试；真实样本验证需要有权访问对应数据和冻结采样。

当前探索版本保持 TEST 隔离。CV 是设备分组验证，不是严格的时间前推验证；重复使用 CV 进行选模产生的最佳分数不能作为独立测试结论。模型复杂度、单次推理延迟、Accuracy、自主比例和目标达标统计仍需按比赛要求补充。
